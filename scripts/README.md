# scripts/

Local utility scripts for seeding test data and exercising backend services.

| Script | Purpose |
|---|---|
| `create_test_league.py` | Create a fake league for development |
| `seed_test_user.py` / `seed_test_user_2.py` | Insert test users with rosters + rankings |
| `publish_test_rankings.py` | Publish canned ranking snapshots |
| `demo_matchup.py` | Run the Claude-powered matchup picker end-to-end |

Run from repo root with the backend's Python environment active.
