# Fleeced voice

Current voice rules, consolidated from the former static memory charter. Visual identity is defined in [brand](../design/brand.md), [tokens](../design/design-system.md), and [components](../design/components.md).

## Writing

Treat dynasty managers as peers. Use natural domain language, lead with the outcome, and ground claims in observable values or evidence. State uncertainty when valuations or forecasts are weak. Separate market consensus, personal value, and projections; never label a result more strongly than the data supports.

Prefer concrete verbs and useful precision. Avoid hype, generic adjectives, canned praise, and summaries that repeat the preceding paragraph. No emoji in documentation, commits, or UI copy. Use ISO dates and units; do not write “today” or “yesterday” in durable records. Commit summaries use `<scope>: <action>`.

## Product copy

Name the action or result directly. Empty states provide a next action; errors state what failed and what the user can try. Avoid exclamation points in default copy and invented precision in trade claims. “Trade calculator” is a valid name for the calculator surface; “Fleeced” names the product. The former blanket replacement of calculator with finder is retired because both surfaces exist.

The mascot is **Fleeced, the ram** (D-155); **The Analyst** is its guide role. Product and character share a name, so avoid ambiguous sentences. Which strings use the character name versus the role remains a product-copy decision. The abandoned fumbling-player concept is historical.

Keep mascot imagery within its approved box. [Mobile asset instructions](../../mobile/assets/CLAUDE.md) define raster/vector exceptions; they do not extend to UI chrome.

## References

Use relative links for internal docs and direct source links for external claims. Tables help genuine comparisons; headings and lists follow the subject rather than a mandatory template for every short note. Long references have navigable sections; compact session briefs do not need a table of contents.

The full [prior charter](../../living-memory/archive/static-2026-09-06/BRAND.md) is preserved for historical rationale.
