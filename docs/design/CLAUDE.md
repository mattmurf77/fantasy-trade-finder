# docs/design/ — Notes for Claude

Read `design-system.md` (tokens) and `components.md` (specs) before ANY UI work in `web/`, `mobile/`, or `extension/`. Live rendered reference: `web/style-guide.html`.

`brand.md` is the visual-identity narrative behind the tokens; `tier-naming-proposal.md` is a proposal, not shipped naming — check current naming in `docs/glossary.md` / `docs/cross-client-invariants.md` instead.

`brand/` is the durable output of the 2026-08-08/09 naming + icon program — `fleeced-icon-masters/` (1024×1024 candidates), the contact sheet, and `brand/README.md`. **The app ships as `Fleeced: Dynasty Trade Finder`** (D-057); the icon itself is not yet chosen.

`icon-explorations/<date>/` is a one-off lab (e.g. `icon-explorations/2026-08-08/`) and is **gitignored** — don't read it to understand current UI, and don't leave anything durable in it (that's how the original program's ~90 marks were lost).
