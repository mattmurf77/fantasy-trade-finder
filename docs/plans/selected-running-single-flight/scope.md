# Exact selected running-job joins

2026-11-07. Authorized bounded 200 ms follow-up from main `57b8d7c3`, isolated branch `perf/selected-exact-request-reuse`. No production action or push before review.

Identical strict selected-player/opponent requests currently start independent full workers; intent-only requests already join through the organic index and retain that behavior. Add a separate bounded in-process running-only index. Preserve ordered raw and effective selectors, exact fairness, user/league/format, same session and original service/league identities, account lifetime, full request/config/flag signature, nonmissing roster/value fingerprints and all participant epochs. Claim/recheck occurs under the existing job lock after source reads outside it. Every caller still uses the normal current-only, authorization, preview, disposition and delivery pipeline with its own search ID.

Only strict `/generate` requests with pins/opponent participate (an additional intent is part of their exact shape); intent-only requests keep existing organic reuse/supersession. headless, grading, prepared, replenishment, synchronous and legacy paths do not. Force always starts fresh. Completed/errored/revoked/stalled jobs never join. Different requests preserve existing independent selected-job semantics; bounded index eviction drops a join handle, never cancels another valid job. This reduces duplicate workers; it does not introduce a global admission limit or solve cold first-request latency.

## Implemented boundary

The index contains at most 128 SHA-256 shape keys and job-ID strings. Encoded shape metadata above 32 KiB skips joining without rejecting/truncating the search. Full shape equality independently checks digest hits. Original source refs live only on the running job and are removed on finish/revocation/timeout/stall pruning; copied job snapshots retain identity, never a cloned authority. Eviction removes only a pointer; it does not cancel a valid selected request. The existing overall job registry/parallel admission remains unbounded by count, with its original hard timeout/retention. This patch is not a global scheduler.

`_kickoff_trade_job` captures original ranking/trade-service/league/player identities, roster order, league seat and account-lifetime state. It reads fingerprints before the job lock, then requires nonempty stored/current signatures and both fingerprints, full epoch equality, exact shape and the existing running-policy checks under that lock. Generic legacy helpers' permissive missing-input behavior cannot admit this new path. Force bypasses joining regardless of the organic force-supersedes knob; different selected requests remain independent. Intent-only generation retains its original organic-index behavior; combined pin/opponent+intent is exact-scoped.

The source binding describes this same live execution and the existing observed-input contract. It is not a full immutable model input, a globally fresh provider certificate, a precomputed deck, or permission to reuse completed proofs. Unknown source, metadata overflow or any mismatch uses normal full generation.
