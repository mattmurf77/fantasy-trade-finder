offer. The private native experiment retained every3,836 emitted proof and the
complete report while compacting49,334 final internal rejections with zero reads
of discarded fields. Its runtime semantic copy must not be integrated.

Introduce one small virtual final-freeze seam in the existing owner search. The
existing owner `_decision` still writes its existing decision/schema fields, then
calls that seam. Its default implementation returns the same frozen
`OwnerDecisionContext` and canonical JSON as before. All existing bilateral

do not duplicate, move or weaken them.

The candidate overrides the final-freeze seam to apply its generator version and
construction metadata **before the single JSON freeze**, eliminating its current
freeze/parse/refreeze cycle. Remove only the candidate's redundant `_decision`
override. Its public single/batch evaluators remain complete diagnostics for

generation entry point. Only its final-freeze seam can return a frozen internal
rejection containing final eligibility=False and reason. Do not expose a request
parameter, new runtime flag or way for external evaluators to select this mode.
All full eligible core/final proofs retain current structure/immutability. No
lazy rebuilding, persistent cache, shared registry or copied policy source.
An attempted read of a discarded rejection payload must fail visibly; test the
actual generation consumers, including companion/core caches and partial paths.
