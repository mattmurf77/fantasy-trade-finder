# DLF (DynastyLeagueFootball.com) Research Report

**Site owner:** Betsperts, Inc. / Betsperts Media & Technology Group (acquired DLF Jan 25, 2022). Same group owns Fantasy Life, 4for4, Betsperts app. ToS entity is "Betsperts, Inc."

**Access note (feasibility-relevant):** DLF blocks non-browser HTTP clients — plain `curl` and WebFetch both returned **HTTP 403** on every page (Cloudflare in front, `cdn-cgi/rum` beacons observed). All page data below was read via a real browser engine. A server-side "fetch on the user's behalf" bot will hit this bot-protection wall unless it drives a real/headless browser with the user's session cookie.

## 1. Dynasty rank sets subscribers get
Source: https://dynastyleaguefootball.com/premium-signup/ and https://dynastyleaguefootball.com/rankings/dynasty-rankings/

- **Sets offered:** Overall Top 250+ Dynasty Rankings, Positional Rankings, Rookie Rankings, **Superflex Rankings**, IDP Rankings, Devy Rankings, and "Cornerstone Rankings" (young vets + future stars).
- **Formats:** **1QB** (default; "assume a conventional PPR scoring system for 1QB leagues") and **Superflex/2QB**. Rookie ranks exist in both 1QB and Superflex/2QB. **TE-premium format: unverified** — DLF's own feature copy and rankings pages do not advertise a TE-premium ranking set (competitors KTC/PFF/DraftSharks do; no evidence DLF does).
- **Rookie ranks:** Individual Rookie Rankings first produced early January; rookies fold into the main dynasty rankings after the NFL Draft.
- **Update cadence:** "constantly updated… throughout the entire year." No fixed interval published (unverified as a number).
- **Individual analyst vs consensus:** BOTH. The table shows a consensus **Avg** rank plus per-analyst columns — observed rankers on the live 1QB board: **Matt T, Patrick M, Richard C, Rob W, Ryan M, Wyatt B** — plus a proprietary **Value** column. Users can click a ranker's name to see that analyst's own ranks/tiers/comments, and deselect rankers to recompute the average. Free (logged-out) view is **capped at the top 10 rows**; the rest is paywalled.

## 2. Export surface for subscribers
Source: rankings page DOM + https://dynastyleaguefootball.com/wp-content/plugins/DLF-RankingEngine/js/shortcodes.js

- **Yes — native "Export PDF" and "Export CSV" buttons** are built into the rankings table (`#pdfexport`, `#csvexport`).
- **Mechanism is 100% client-side:** `shortcodes.js` walks the rendered HTML table cells, builds a CSV string (`'\ufeff'` BOM + comma-joined rows), and triggers a `data:text/csv;charset=utf-8,…` download named `<rankTitle>-<date>-<time>.csv`. PDF export uses bundled `jspdf` + `jspdf.plugin.autotable`. A `blob:` download was observed on the page.
- **Implication:** there is no server "download endpoint" — export just serializes whatever ranking rows are already in the page DOM. A logged-in premium session that loads the rankings page has the full table in the HTML and can either click Export CSV or read the table directly.
- **Print/cheat sheets:** Premium also includes **printer-friendly Rookie Draft Cheat Sheets** in 1QB and Superflex/2QB (PDF-style, separate from the CSV export). No Google Sheets integration found.
- **Trade Analyzer "Values" CSV:** DLF's Trade Analyzer FAQ (per search snippet) states subscribers can view 1QB and 2QB/SF **player values and "download either of those to a csv file"** via a "Values" submenu link — a second CSV export surface. (FAQ page itself returned 403 to direct fetch; sourced from Google's index of https://dynastyleaguefootball.com/dynasty-trade-analyzer-faqs/.)

## 3. API / how rankings render / mobile app
- **No JSON/REST data API observed.** On loading the rankings page, the network log showed **zero XHR/`admin-ajax`/`wp-json` data calls** — the ranking rows are **server-rendered directly into the page HTML** (paywall gates row count server-side). No named public API endpoint appears in docs or the client JS.
- **Stack: WordPress** (generator `WordPress 7.0.4`). Rankings powered by a **custom in-house plugin `DLF-RankingEngine`** (theme `dlf_code_optimised23`). Other plugins: Elementor/Elementor Pro, MemberPress, WooCommerce + WooCommerce Stripe gateway, Popup Maker, Contact Form 7, Google Tag Manager.
- **Known third-party scraper precedent:** an open project (https://matthewdane.com/dynasty-league-football/) uses **Selenium** to log in with DLF credentials and scrape the four positional ranking tables; it notes that **without login the scraper gets only the first 10 records** — independently confirming the 10-row free cap and that there's no clean API, only DOM scraping behind auth.
- **Mobile:** DLF ships **web-based "apps"** (Rookie Draft App, Startup Auction App, Dynasty Score App, ADP Over Time, ADP/Ranks Grid, League Analyzer, etc.) — these are browser tools on the site, not clearly native store apps. A dedicated DLF native iOS/Android app is **unverified**.

## 4. Login / auth mechanism
Source: login form DOM at https://dynastyleaguefootball.com/login/

- **WordPress + MemberPress membership plugin.** Login form POSTs to `/login/` with fields `log`, `pwd`, `rememberme`, `wp-submit`, `redirect_to`, **`mepr_process_login_form`**, `mepr_is_login_page` — the `mepr_*` fields are MemberPress's login handler. Password reset at `/login/?action=forgot_password`.
- Standard username/password session-cookie auth. **No OAuth / SSO / social login** surfaced. Billing via **Stripe** (WooCommerce Stripe gateway) + MemberPress subscriptions.

## 5. Terms of Service — automated access / redistribution / sharing clauses
Source: https://dynastyleaguefootball.com/terms/ (last updated Aug 30, 2024; "Betsperts" ToS)

Short quotes (<15 words each), with section:
- **§5.7 No Resale:** "you agree not to modify, reproduce, sell… or distribute any part of our Platform, including any data".
- **§5.1 License scope:** grants access "solely for your own personal use."
- **§5.3(ix) Anti-circumvention:** "bypass any measures we may use to prevent or restrict access to the Platform".
- **§5.3(xiv):** may not "reproduce, republish, download… distribute, copy, publicly display or otherwise use any Content… or any derivative works".
- **§5.3(viii):** may not "interfere with or disrupt the Website, the Services… or servers or networks".
- **Account sharing — §2.3:** "you are limited to 1 username or email address per person"; sharing credentials makes you solely responsible ("such as by sharing your account credentials with others").
- **§5.3(x):** may not "sell or otherwise transfer your account or Subscription."
- **Note:** the ToS has **no explicit standalone "scraper/robot/spider" clause** (unlike sibling site language found elsewhere), but §5.3(xiv), §5.7, §5.1, and the anti-circumvention clause together broadly prohibit downloading/redistributing ranking data and using it outside personal use. A "log into DLF and fetch rankings into another product" feature runs directly against §5.1 (personal use), §5.3(xiv) (download/use of Content), and §5.7 (distribute any data). **Legal review recommended before building.**

## 6. Licensing / "powered by DLF" third-party integrations
- **No evidence found** of DLF rankings being officially licensed into or "powered by DLF"-branded in any third-party app (searched Sleeper integrations, competitor tools, partnerships). DLF's own **League Sync** imports the user's league *into DLF* (inbound), not DLF data outbound.
- Existing DLF-data-in-other-tools cases are **unofficial scrapers** (e.g., the Selenium project above), not partnerships. Verdict: **no known outbound data-licensing precedent (unverified/none found).**

---
**Bottom line for the caller:** DLF gives paying subscribers full 1QB + Superflex consensus *and* per-analyst dynasty/rookie ranks with **built-in CSV and PDF export** (client-side, table-to-file) plus a separate Trade-Analyzer values CSV. There is **no public API**; rankings are server-rendered HTML behind a **MemberPress/WordPress login**, and the site sits behind **Cloudflare bot protection that 403s non-browser clients**. So "fetch rankings on the subscriber's behalf" is technically a headless-browser login-and-scrape/click-export operation, not an API call. The **ToS (personal-use license + no-download/redistribute + no-resale-of-data + anti-circumvention) is the main obstacle**, and no precedent exists of DLF licensing its data into third-party tools.
