# ETR (Establish The Run) — Dynasty Rankings Import Research

## 1. Dynasty rank sets

ETR is primarily a redraft/best-ball/DFS shop, but it does maintain year-round dynasty products:

- **Dynasty Rankings (1-QB)** — "include contract status and are adjusted for age"; authored by **Anthony Amico** (https://establishtherun.com/fantasy-football-rankings-hub/)
- **2-QB/Superflex Dynasty Rankings** — with a sortable **SF/TE-Premium column** (TEP is a column variant, not a separate rank set) (rankings hub, same URL)
- **Dynasty Rookie Rankings** — rookie-only drafts, also Anthony Amico; offered in 1QB and 2QB/SF-with-TEP variants (https://establishtherun.com/dynasty-rankings-2/)
- **Dynasty Rankings Change Log** — establishtherun.com/etrs-dynasty-rankings-change-log/
- Cadence: dynasty page says "continuously updated year-round" with the change log tracking edits; no fixed schedule published (redraft products advertise "updates 9am daily"; dynasty does not). Exact dynasty cadence: **unverified**.
- Brand leads are Evan Silva and Adam Levitan, but the dynasty sets specifically credit Amico.

## 2. Export surface for dynasty

- Dynasty rankings render as an **embedded web table on the paywalled page** — the page loads the **Ninja Tables** WordPress plugin (`ninja-tables/assets/css/ninjatables-public.css`, custom CSS for `ninja_table_custom_css_1124711`), i.e. an on-page interactive table, not a Google Sheet embed.
- **CSV download for dynasty: unverified.** No CSV/Sheets mention on the dynasty page, subscribe page, or FAQ for dynasty. (Ninja Tables Pro *can* enable an export button, but I could not confirm it's enabled without a subscription.)
- Contrast: ETR's **Best Ball** product is explicitly "Continuously updating & **uploadable** Rankings for every Best Ball platform" (https://establishtherun.com/subscribe/), and Underdog ranks pages instruct users to "download the rankings CSV" for Underdog's upload button (https://establishtherun.com/etrs-top-300-for-underdogfantasy/). So CSV export is an established ETR pattern for best ball/DFS — just not confirmed for dynasty.
- FAQ (https://establishtherun.com/faq/) has no delivery-format or export details for dynasty.

## 3. API / tech stack

- **WordPress, confirmed** by response headers: `cf-edge-cache: cache,platform=wordpress`, `link: <https://establishtherun.com/wp-json/>` (behind Cloudflare, with Cloudflare APO).
- **No official public API.** WP REST API (`/wp-json/`) is exposed as standard, but ranking content is membership-gated.
- Rankings pages are **server-rendered and server-stripped for non-members**: logged-out HTML carries body classes `restricted has-membership-paywall` and the table markup is absent — the paywall is server-side, not CSS-hidden. For members, Ninja Tables either inlines data or fetches it via `admin-ajax.php` (the plugin's known data path); which mode ETR uses is **unverified** (not probed, to avoid paywall bypass).
- **No mobile app** — no ETR app found on the App Store; presence is web + Apple Podcasts + YouTube only. (Their DFS tooling lives in a separate product, The Solver — thesolver.com.)

## 4. Login / auth

- **Native WordPress auth**: login links go to `wp-login.php?redirect_to=...`; no social login plugins (no Nextend/OAuth traces in page or login-form HTML).
- Membership/commerce stack (from `wp-content/plugins/` in page source): **WooCommerce + WooCommerce Memberships + WooCommerce Subscriptions + Stripe gateway** (plus Ninja Tables, Metorik). So "log into ETR on the user's behalf" means posting a WordPress `wp-login.php` form and carrying WP session cookies — behind Cloudflare, which may bot-challenge automated logins.

## 5. Terms of Service (https://establishtherun.com/terms/)

Directly adverse to the proposed feature on four axes:

- Scraping/automation (§2 Service): prohibits "any automated or non-automated 'scraping'" and "using any automated system, including … 'robots,' 'spiders,' 'offline readers'".
- Account sharing (§2): prohibits "sharing account log-in information so multiple persons are able to access" a paid account.
- Redistribution (§3 Proprietary Rights): users "agree not to sell, license, rent, modify, distribute, copy, reproduce, transmit" content or "create derivative works".
- Commercialization (§2): prohibits "monetizing Establish The Run, LLC content through advertising, subscriptions or other means".
- Also (per ToS): users are "responsible for maintaining the confidentiality of the password and account".

Net: even user-authorized fetching would violate the automated-access clause, and displaying the rankings inside a monetized third-party app hits the derivative-works/monetization clauses. A license deal would be needed.

## 6. Licensing precedent — yes, it exists

- **The Solver** (thesolver.com; https://establishtherun.com/the-solver-dfs-optimizer-and-bankroll-tracker/): DFS optimizer co-founded by ETR's founders. "If you're an ETR In-Season subscriber, projections and projected ownership will auto-sync to The Solver" — matched by using the same email on both accounts (thesolver.com/faq). This is exactly the entitlement-sync model (partner-side verification, not credential scraping).
- **FantasyLabs** (https://www.fantasylabs.com/pricing-etr/): "ETR and FantasyLabs player projections preloaded" into FantasyLabs optimizers, with "*ETR projections require separate subscription*" — a second live example of ETR data licensed into a third-party tool gated on the user's own ETR subscription.
- **Underdog Fantasy**: content-partner relationship; ETR publishes Underdog-specific Top-300 CSVs designed for upload into Underdog's draft applet (user-driven CSV upload, not an API integration).
- All known precedents are **DFS/best-ball projections; no known precedent of dynasty rankings licensed into a third-party tool** — unverified/none found.

## 7. Price of the dynasty tier

- **NFL Draft Kit Pro — $54.99/season** is the tier listing "Dynasty Rankings + Dynasty Trade Calculator" (plus redraft rankings) (https://establishtherun.com/subscribe/).
- Also included in the **Draft Kit Pro + In-Season bundle — $299.99/season**. No standalone dynasty-only or monthly dynasty product found.

## Bottom line for the feature

Dynasty rankings exist (1QB + SF/TEP + rookie, Amico, continuously updated) but are a server-side-paywalled Ninja Tables web page on a WordPress/WooCommerce Memberships site with plain wp-login auth and no API; no confirmed CSV export for dynasty. ETR's ToS expressly bans automated access, credential sharing, and monetized reuse — so "log in and fetch on the user's behalf" is a clear ToS violation. The viable path has precedent: an entitlement-sync partnership like The Solver (email-matched subscription check, data delivered via licensed feed), or user-driven CSV upload like the Underdog pattern if ETR enables dynasty CSVs.
