# Calibration complete held metadata and pair-scoped coverage

The ordinary Sleeper cache deliberately retains named QB/RB/WR/TE rows. Calibration previously consumed that filtered cache as if it covered all held K/DEF/IDP assets. This made complete real rosters fail structural validation even after fixed-slot support was introduced.

Calibration capture now obtains a separate compact public full-position observation when an actual held ID is absent from the filtered cache. It retains five eligibility/availability fields, with a 50,000-row/20MiB stored-payload cap, atomic replacement, a 20-hour capture refresh interval and process/thread refresh coalescing. It does not add candidates, prices or usable offensive depth to the normal ranking pool. The network transport remains the existing provider reader; these caps bound the retained compact payload, not the provider transport's initial response allocation.

Only actually held facts and observation time are saved with each private exercise. Reads/currentness never fetch full metadata. A deployment that loses the ephemeral cache retains the frozen as-of observation; a valid newer observation supersedes it, including explicit row removal. This is historical comparison freshness, not a claim of continuously refreshed live availability. The first fingerprint binds the exact consumed observation; the final check detects a newer observation that appeared before or during the capture window. Provider-rules and ordinary input checks remain in place.

A player spanning offensive and fixed-position domains is never silently converted into a disjoint sentinel. When that player belongs to the viewer, capture explicitly refuses the unsupported configuration. When the player belongs only to an opponent, both arms still generate their full unchanged inventory and budget, then remove all pairs involving that unsupported participant before the existing safety/publication gates. Relative order at the pair-filter boundary remains intact. Existing downstream presentment and quality/repeat rules then run on eligible pairs; their ordinary deferral can change final deck order compared with removing cards from an old final deck. Unsupported cards do not consume repeat limits. Private source retains participant/holding reasons; each arm records native, unsupported-participant, removed-pair and downstream survivor counts. These are partial-league comparisons and cannot claim full-league model coverage.

If the extra defensive eligibility has no eligible slot in the actual configuration, the effective intersection can be offensive-only. Original and effective eligibility and the configured-slot basis remain in private provenance, including raw ESPN eligibleSlots. Every manager receives the same captured offensive formation and native reserve/taxi exclusion in both models; K/IDP cannot cause format-default formation fallback.

Exact joint offense/defense optimization for a coupled roster remains outside this bounded repair. It would require one shared assignment across both domains, conditional fixed capacity/depth, and consistent model/gate handling. Missing identities/credentials, unknown assets and other unrepresentable rules remain explicit failures; this patch does not bypass authorization, quality thresholds or source freshness.

No ordinary-serving, public flag, mobile binary, grading-history, provider-write or production mutation is included. Exposed/answered cohorts remain frozen. Unexposed source-bound cohorts must be reprepared after release, then their actual readiness/currentness checked before activation.
