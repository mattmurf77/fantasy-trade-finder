### F-2: `completed_draft_seasons` ignores a completed startup-shaped current-season draft that the old #228 loop excluded
- Severity: minor (in-spec — PRD §3 F1 says "rookie-shaped-or-unknown" — but it is a behavior change from #228 that PRD §6 / build report §6 list as "not changed", and it is untested at the sync level)
- Repro (code path): a Sleeper league whose only current-season draft is `{"status":"complete","season":"2026","settings":{"rounds":25}}` (a first-year dynasty league after its startup). Pre-#428 sync (`15dabe05` `server.py:13330-13337`) excluded 2026 on any `complete` + `season == cur` entry, shape-blind. Post-#428, `completed_draft_seasons` (`backend/draft_status.py:176-177`) skips it because `_is_rookie_shaped` returns `False` for `rounds >= STARTUP_MIN_ROUNDS` (15) (`:306-316`), and — because `drafts` is non-empty — the cached verdict is not consulted (`server.py:13354`). Result: the grid keeps 2026 rows for that league, and the send-time window (same predicate, `:30397-30400`) also keeps 2026 in-window, so a 2026 pick from such a league reaches Sleeper and is refused with F3's sentence instead of the 422.
