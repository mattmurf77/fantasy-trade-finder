## C. Rulings on the six open questions

1. **Consensus collision ordering — accept the asymmetry; specify the invariant at the outcome level.** Required invariant: *after `_emit` enumeration, at most one card carries the balanced key and no bare card survives whose balanced key is present.* Both orders satisfy it: bare-first sweetens in place (`:7228-7234`) and the later organic sibling dies at `:7138-7139`; sibling-first hits the new `else: return`. Because 1×1s enumerate first (`:7265-7271`), the only reachable sibling-first case is the two-bares-same-combo case (objection 8). Do **not** make consensus order-independent by pre-populating `seen` — that would require a second enumeration pass for no observable gain. The survivor's annotation differs by path (in-place carries `gap_sweetener` + the R-C line; an organic sibling carries neither) — acceptable, and T-7 must therefore assert key-level facts only.
2. **v3 post-loop drop — accept "pair −1 per collision"; no backfill.** The next-best candidate lives in `scored` above the picker (`trade_optimizer.py:647-657`) and would need the overlap/diversity walk re-entered after the 3.4 rescue and the gap pass; the served deck is F7-over-generated and globally ranked in `_dedup_and_sort` (`trade_service.py:6449`), so a per-pair count is a generation budget, never a deck cap (D-154's rule). Record it in D-176's consequences.
3. **gen_v2 — no collision rule, confirmed.** Arm C sweetens at enumeration (`trade_gen_v2.py:737-802`, `s_give, s_recv` rebound at `:802`) *before* `_dedup_batch` (`:857-882`), so a closable bare never reaches dedup as bare; the exact-key duplicate with the organic sibling collapses at `:865-867` and the two differ only in annotation. An unclosable bare with an organic balanced sibling cannot occur: the sibling passed `filler_ok`/`g6_*`/ε/band with X1 (`:657-706`), so `_gap_gates_ok` (`:591-628`) accepts X1 too, unless a cheaper asset closed first — which yields a different balanced sibling, Jaccard 0.5, both kept. Required: T-4a arm C asserts no surviving card for R is bare with gap > eff.
4. **Shape drift — watched, not gated, confirmed — with one pre-registered tripwire.** A shape gate in the helper would contradict a shipped pin: `test_gap_sweetener.py:325` already asserts a 3×1 produced under `v3_shape_max_delta` 1 (`:321-330`). Pre-register in TEST_LEDGER: if the prod replay's 3×1 share rises by more than **+5 pp absolute** at frac 0.10 vs 0, the builder reports before merge (operator decides); no auto-block. Note `test_shape_knob.py:137-138` pins the pass off, so it cannot detect this.
5. **Consensus epsilon window — explicit test required** (objection 11, T-4a-ov). Existing coverage is absent: no consensus test exercises an equalizer that overshoots.
6. **Lever surface — `PUT /api/admin/config/<key>` only** (objection 5). `server.py:18577-18601`, `X-Cron-Secret` per `_require_cron_auth`, reload inline at `:18600`; startup reload at `:449`; no other reload path exists (`git grep reload_config backend/server.py` = those two).
