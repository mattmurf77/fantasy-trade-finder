- Single-pin mode: `singlePin` (`:1087-1093`), `singlePinFeatured = !firstRun && !!singlePin` (`:1106`), `singlePinDeckActive = singlePinFeatured && deck.length > 0` (`:1107`, #298: keyed on `deck.length`, **not** `topCard`, so the deck keeps the slot through swiped-out and summary states).
