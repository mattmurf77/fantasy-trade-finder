Every candidate trade in league 1312140920132497408, and the rule that killed it. Replay of 2026-08-19 production data through the real engine. Boarded: mattmurf77, Bcork, gdubs10, jonbonjourvi, johnstanfield, MangoPatti. Fairness threshold 0.5.

How to read this

First-kill is the waterfall: the rule that actually rejected the candidate, in real execution order — each rule only sees what earlier rules let through. Would also fail ignores order: how many of the whole universe that rule rejects when asked independently. Unique kills is the number this exercise exists for — candidates no other rule would have rejected. A rule with a big first-kill count and a small unique count is mostly doing work something else would have done anyway; a rule with unique kills is the only thing standing between the user and those trades.
