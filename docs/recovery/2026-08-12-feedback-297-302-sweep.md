## 3. The one superseded branch

**`feedback-integration-297-302` @ `49e48ef` was NOT merged, and its content is
deliberately not on `main`.** Recorded so a future reader does not mistake the
filename check for a merge.

It held the batch's **first** analytics round, built against `origin/main` @
`ab9368f`. While it was in flight `main` advanced 21 commits and the P0-7
remediation round registered `league_team_opened` — which covers the same
League drill-in the round had just minted a `league_team_focused` /
`league_team_unfocused` pair for. Its premise ("no registered event covers this
drill-in") was **true when checked and false by the time it finished**.

The round was discarded and redone on `feedback-integration-v2`, which adopted
the shipped `league_team_opened` and added only the genuinely missing exit
event. The v2 work is what shipped in PR #108. The v1 files exist on `main`
with **different content** — same paths, different design.

The reasoning is preserved in [`D-038`](../../living-memory/DECISIONS.md) and in
the tracking plan under
`docs/feedback/items/297-lineup-impact-single-pin/`, so nothing is lost by
deleting the branch. **The generalisable lesson is recorded there too: an
instrumentation gap analysis is only valid against the `origin/main` it will
land on.**
