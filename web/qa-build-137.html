Part A — Shop, flag on

The flag is already on in prod — run as-is on the new build. What changed since rev-2: the shop is a pushed window, the position filter row sits at the top and applies to every mode, Same value pools by tier with an auto-widen default, and the window mounts its own feedback button.

1Entry, one give asset
On the Trades deck, the button under the players you send reads "More offers"; under the players you get it still reads "Keep · more offers". Tap the give-side button on a card with ONE give asset → a new screen opens ("Shopping <name>" in the header) — the deck did not clear or regenerate behind it.
2Entry, several give assets
On a card sending 2+ assets, the same tap opens a "Shop which player?" sheet listing every give-side asset (players and picks). Cancel closes it with no other effect — you're still on the deck. Picking a row opens the window for that asset.

Three chips — Tier up / Tier down / Same value — each with a live count; Tier up selected on open. A zero-count mode shows named copy ("No tier-down offers cleared the bar"), and the "other modes have offers" pointer renders only if that's true.
6The pager is honest
Swipe through the tiles: the "1 / X" counter tracks exactly, X = tiles actually present. Reaching the end doesn't advance, dispose, or wrap.

8Same value = the tier, priced honestlynew semantics
A Same-value offer may sit noticeably above or below the shopped player's value — that is the tier: the pool is his whole rung of the pick-valuation ladder now, not a ±10% band. Each card's signed diff still shows its real gap. If every idea looks suspiciously identical in value, the tier scope regressed to the band.
9Auto-widen is loud, never silentnew
With no chips selected, if Same value would be empty at his position it re-sweeps all positions and shows "Nothing at <POS> — showing all positions" above the results. Select any chip explicitly → the notice disappears and only your selection is searched; clear it → the default (and notice, if needed) returns. Tier up / Tier down never auto-widen.
10Like = a real offer
Tap ✓ on a tile → success toast in the window; the trade appears queued in the usual counterparty flow. ✓ the same tile again → same success copy (idempotent), not an error. A refusal (e.g. an untouchable involved) names the reason. Ruled: this like does move your Elo board.
11Dismiss + Undo, the honest version
Tap ✕ → the tile leaves the pager, X drops, "Dismissed · Undo" toast appears. Tap Undo within 5 s → the tile returns exactly where it was, counter restored.
12Undo never liesQA B-4

13Dismissals stick
Dismiss a tile, switch position filters away and back (or switch modes) within a minute → it does not come back — only Undo restores a tile. Go back and reopen shop on the same player → a fresh session; the server cooldown governs what returns (a dismissed package stays gone).

Also owed — partner shape lines (#384)

The Aug 27 fix, waiting for its first on-device look. Prereq: a league with 3+ leaguemates whose rosters differ by position, at least one owning draft picks. A "shape line" looks like: QB ≈1 first · RB ≈2 firsts · WR ≈3 firsts · TE ≈0.5 firsts · Picks ≈2 firsts.

1The shape line existsthe regression
Open the In-league calculator → tap the Team dropdown. Every leaguemate row shows the handle on line 1 and a shape line on line 2, QB/RB/WR/TE in position colors; the R / R* / NR badge fully visible on the right. Before the fix, line 2 was absent.
2The numbers differ and make sense
Read three rows: numbers differ between teams and track the rosters (a QB-heavy team's QB segment leads). All-identical or all-zero means the rankings feed is failing, not this fix — report that separately.
3No-picks tail
A member with no future picks (or the ESPN case): their line ends at TE — no trailing "· Picks", no empty separator.
4Picks tail, pick-equivalent wording
A member with picks: a "· Picks ≈N firsts" tail in the same wording as the rest. No raw numbers like 4,200 anywhere on the line — a numeric means the server dropped the label; note which member and segment.
5Landscape / large text
Rotate to landscape, or set Larger Text two steps up, and reopen the sheet: the shape line wraps to at most two lines and ellipsizes with "…"; the badge stays on screen; rows stay tappable.
6Tap still selects
Tap a member → sheet closes, the Team dropdown shows that handle, the calculator re-prices for them exactly as before (the reflow must not have broken the tap target).
7VoiceOver speaks the shapethe sighted-only failure
VoiceOver on, swipe through the rows: each row is announced as one element — "@handle, ranked, QB about 1 first, RB about 2 firsts, … picks about 2 firsts, button". A row read as only "@handle, ranked, button" is the failure — report it.
8Long sheet scrolls
With 8+ leaguemates: the sheet scrolls, doesn't grow past ~60% of the screen, and nothing hides under the home indicator.
When done, log the outcome in living-memory/TEST_LEDGER.md. Anything that fails: the feedback button, right from the failing screen.
