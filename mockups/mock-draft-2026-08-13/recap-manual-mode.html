Rationale & drawing checks

  • Zero layout change is the finding. The shipped recap already keys everything user-facing on picked_by_user_id (header count, “Your draft”, tinted rows) — manual mode flows through it untouched. The frame exists so the PRD/build can see the correct end state and not “fix” the 4-vs-48 surprise by re-keying on by (T-305-02's sabotage).
  • The header card is where the surprise lands. A user who just tapped 48 times reads “4 picks”. That is correct — it is their team's draft — but worth one PRD decision: an optional one-line disclosure under the meta (e.g. “You made every pick in this manual mock.”) would name the distinction on the surface itself. Not drawn as committed UI — flagged as a PRD copy option, since LLD §3.4 specs no recap change.
  • Owner names depend on the D-16 fifth-site fix. Every “Round N” row here shows a name only because the build adds the caller (and keeps members) in _mock_usernames (LLD §1.3/§11.3) — without it the user's own rows would render “Unassigned” on a plain Sleeper league. The frame assumes that fix landed.
  • Consensus-delta column stays honestly absent (shipped gap G3 note in source): picks[] carries no rank/value, so no “+3 vs consensus” is drawn — same omission as CPU mode.
