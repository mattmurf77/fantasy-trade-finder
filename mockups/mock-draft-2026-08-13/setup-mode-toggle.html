Manual selected: only two things change — the active segment and the footnote, which now states that the user makes every pick and (unchanged promise) nothing touches the league. The footnote branch is LLD §3.2's spec; its manual-mode sentence here is a placeholder — PRD owns the final wording.

Rationale

  • Same control, same field grammar. The mode control is the fourth field in an existing three-field sheet — label in 11px caps, TypeSeg segments, 44px touch floor. Nothing new to learn; the sheet stays a confirmation, not an interrogation.
  • Placement below Pick order per LLD §3.2 — the two “how the draft runs” controls (order, mode) sit together, after the two prefilled facts (team, rounds).
  • Mode is create-time-immutable (HLD §4.2). The sheet is the only place mode is ever chosen, which is why the segment labels must explain consequences in plain words rather than say “CPU”/“Manual” bare.
  • Footnote is the disclosure surface. The shipped sheet already uses the footnote for the nothing-touches-your-league promise; the manual branch keeps that promise verbatim and swaps only the who-picks clause. Two-sentence max — this is a footnote, not a tutorial.
  • Drawing check that worked: the LLD's placeholder labels fit the segments only when wrapped to two lines. That is legal (min-height grows, 11px floor respected) but tight — flagged for the PRD as a length budget: segment labels ≤ ~14 characters per line at 11px caps in a 179px segment.
