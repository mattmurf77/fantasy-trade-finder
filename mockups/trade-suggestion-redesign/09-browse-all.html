Rationale

The pyramid: 1 endorsed hero → a small Featured tier → an uncapped ranked browse list. Scarcity powers the endorsement (Hinge, Tinder), but discovery stays open because every view and every dismiss-after-view is ranking-training signal (the PoF reply-rate patent's P(response) loop applied to trades; IBM/ESPN's 76.9→97.3% jump came from mining declines). The dismiss control is on every row, and the response is acknowledged in-product — "we'll rank ideas like this lower" — so the model's learning is visible (round-2 §5.9).
