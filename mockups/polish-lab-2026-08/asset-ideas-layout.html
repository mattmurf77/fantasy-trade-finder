Tapping "More options" expands the same grouped Upgrade / Lateral / Downgrade rows beneath the lead card (which compresses its verdict to one line to stay in view). Rows drop the raw ↔ value pair — the signed diff chip carries the number, honoring "too much info is worse than none". "Fewer options" collapses back.

Why this design

  • Answer first, menu second (#216). A user who pins a player wants "what's my best trade for him?" — so the top of the screen IS that answer: one full card with the value bar visible, not a taxonomy of options to study first.
  • Depth on demand, in place (#216). The Upgrade/Lateral/Downgrade groups survive untouched behind "More options" under the trade-away column — the exact spot the operator named — so power users lose nothing and newcomers never see it uninvited.
  • One side order everywhere (#209). Code check: today's TradeCard already puts "YOU SEND" left; it's the pin board that's flipped (TRADE FOR left). Proposed swaps the board to away-left / for-right so board, card, and ideas rows all read give → get, left → right.
  • Fewer numbers per row. Idea rows keep only the counterparty + the signed diff chip; the raw value pair (8010 ↔ 8450) moves behind the tap into the calculator, which already itemizes it.
  • Zero-context labels. "Best trade for Breece Hall" and "More trades for Breece Hall" replace the abstract "Ideas for trading away" framing — no app concepts needed to parse the screen.
