League home — progress-module fold (#243 scroll audit)

The #243 scroll audit (docs/feedback/items/243-scroll-audit/league-misc-surfaces.md, §2) found that on LeagueScreen.tsx's low-activity state — a quiet/new league (0 matches, ring <4/4, contrarian insufficient_data) — the page's single most important first-run explainer, LeagueProgressModule, starts too low and gets clipped by the tab-bar viewport. Usable-viewport budget for a Main-tab screen (iPhone 15/16-class, 393×852), same method as the #218 hub density pass:

852 − 59 (top safe inset) − 52 (TopBar) − 49 (tab bar) − 34 (bottom inset) = 658pt

Contributing waste: a divider double-margin bug (styles.divider carries its own marginTop: space.md(12) on top of the ScrollView's own gap: space.md(12) — 24pt spent for what should be a 12pt gap, ×2 dividers in this state) and three stacked Explore rows at ~67pt each (201pt) that could reflow denser. All three frames below use the same data (positions 0/4 ranked, 1/12 ranked-incl-you, 12 teams — identical to the shipped empty-states-progress-v3 mock) so only layout changes, never content.

  • Recommend V1. It resolves the audit's root causes (items 1–3+5, ~108–138pt reclaimed depending on measured render) rather than shuffling the same bytes around, and the divider fix alone is worth landing project-wide regardless of which layout wins — every other divider on this screen (and likely others) pays the same 12pt tax.
  • V2 is the right move only if Explore genuinely has near-zero value in the low-activity state (arguably true — a brand-new user has nothing to rank/explore yet) and the team wants a same-day, zero-visual-risk patch while V1's tile reflow gets proper design review. It's a reasonable stopgap, not a replacement for V1.
  • The two are not mutually exclusive: V1's density fixes (divider, hero padding, inline invite link) can land underneath V2's reorder later if both the "explore is de-prioritized" and "nothing should look bloated" arguments are accepted — but ship V1's fixes first since they carry no downside.
