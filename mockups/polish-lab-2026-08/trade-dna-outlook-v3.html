V3 rationale — what changed from v2

  • Multi-select made undeniable (operator confirm). It was always the v2 spec ("multi-select within a row is fine") but v2's frames showed one selection per row, which read as radio behavior. V3 demonstrates it in both states: collapsed lists every selection ("Chasing WR · TE — Shopping QB · RB"), expanded shows two filled toggles per row, and both group labels now carry an in-UI "· multi-select" caption so the rule survives without this document.
  • Untouchable mini-cards, collapsed only (operator ask). The bare count told you protection existed but not who — the one fact you actually want at a glance before shopping a player. Mini-cards are read-only pill chips: 6px round position-color dot + last name, ink-2 fill, hairline border. Capped at 3 + a mono "+N" chip so a 10-player list can't blow up the compact card; the row wraps under long names. Not tappable — Edit stays the panel's single affordance.
  • Expanded keeps the count. Per the operator the mini-cards are for the initial, collapsed version only — the editor keeps v2's "Untouchables 5 protected · Manage" line. Duplicating the chips there would just pad the editor's height for a list you manage behind Manage anyway.
  • Cost of the chips: +29px. Collapsed grows from v2's 111px to 140px (measured) — still −61% vs v1's 355px, and all three finder modes stay above the 600px fold with room to spare.
  • Position color is never the only encoding. Chip dots pair with the name, and position is recoverable in Manage; summary minis keep their QB/RB/WR/TE text labels, per the a11y floor.
  • Everything else is v2 verbatim. Outlook chip + tight cards, toggle fill/check mechanics, chase/shop mutual exclusion, passive NEED/DEPTH tags, the WR-fill contrast build note, and the deck bias receipt.
