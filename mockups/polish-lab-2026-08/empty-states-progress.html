Rationale

  • Lead with what works now (#229): the day-one page opens with a "Works right now" card — consensus-priced trade finding needs zero leaguemates — with exactly one action (Find a trade). The sample trade is honestly labeled EXAMPLE — not from your league (flare = informational highlight, ADR-005).
  • One progress module owns every unlock (#230 + #234): the ring makes "rank your players" the visibly unfinished foundation, the 12-slot bar counts ranked leaguemates (you included, honestly: "1/12 (you)"), and one plain unlock sentence — "2 more ranked leaguemates unlocks mutual matches" — replaces the buried "100% to go" coverage hint.
  • Kill demotivating zero-rows: the 0-value Matches tiles, the empty contrarian card, the 0% coverage card and the empty league leaderboard collapse into one line inside the progress module ("appear once 3 leaguemates have ranked") and return unchanged the moment they have real data — five "nothing here" surfaces become one forward-looking one.
  • Honesty rules respected: no fabricated league data, no fake sample rows presented as real; every number shown is the same truth the current screen shows, restated as distance-to-unlock instead of absence.
  • One story across surfaces: the Matches empty state reuses the same unlock module and the same primary action, so League home and Matches can never disagree about what to do next (mirrors the FB-91 tiles-mirror-segments rule).
